# Reports semanais

Regra do orientador: **um report toda segunda-feira, sem exceção**, dizendo o que foi feito na
semana anterior e **o nome de quem fez cada tarefa**.

Um arquivo por semana, nomeado com a data da segunda-feira: `2026-09-08.md`.

## Modelo

```markdown
# Report semanal — semana de DD/MM a DD/MM

## O que foi feito
- **Nome:** tarefa concluída — resultado ou artefato gerado (link/arquivo).

## Em andamento
- **Nome:** tarefa — o que falta.

## Bloqueios / dúvidas para o orientador
- ...

## Próxima semana
- **Nome:** tarefa planejada.
```

O painel (`../../app/`) também gera o texto da semana a partir das tarefas concluídas — use como
ponto de partida e complemente com o que não vira tarefa.
